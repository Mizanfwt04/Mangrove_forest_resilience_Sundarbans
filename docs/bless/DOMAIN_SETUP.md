# BLESS subdomain setup — bless.thegains.org

1. Create the public repository `Mizanfwt04/BLESS`.
2. Copy `index.html`, `styles.css`, `main.js`, and `CNAME` from this directory to the repository root.
3. In GitHub Pages, deploy from `main` and `/ (root)`.
4. Set the custom domain to `bless.thegains.org`.
5. In the DNS provider, create `CNAME` host `bless` pointing to `mizanfwt04.github.io`.
6. After the DNS check succeeds, enable **Enforce HTTPS**.
